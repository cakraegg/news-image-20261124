# news-image-20261124 — THE WORLD IN ONE PAGE

Entry for make.fun `news-image-20261124` ("Sum up 24 November's world news
in one image") by @cakraegg.

The program is `main.py` (Python 3.13, standard library only). It copies the
locked front-page image `assets/entry.jpg` to `/output/entry.png` — the same
bytes on every run, no network, no randomness.

The front page names Tuesday 24 November 2026 and sums up the day: the U.S.
blacklisting Singapore-based Megaspeed in the Nvidia chip-spy row (lead),
Zelensky urging four-way peace talks, the Pentagon rebuking Canada, the EU
hunting a new ECB chief as Lagarde resigns, the Indonesia factory fire, and
a Russian drone clipping Polish airspace — plus a one-line joke at the foot
of the page.
